# Integrated Library System web app in NodeJS (SQLite DB storage)
* Register/login
* Add book and request book information by ISBN/barcode
* Lend/return books
* Write review and rate book

# Barcode Scanner app in Python and Kotlin for Android smartphones
* connect to PC
* scan barcode and automatically print it to the PCs focused input field
* you may use this command in case the printing to the PCs focus does not work:   sudo setfacl -m u:$USER:rw /dev/uinput
